# WitcherQuiz

Мобильное Android-приложение формата мини-квиза по вселенной «Ведьмака» (на основе книжной саги Анджея Сапковского и серии игр CD Projekt RED).

## Функционал
- **Локальная база вопросов:** вопросы и варианты ответов загружаются из JSON-файла (`assets/questions.json`).
- **Два режима сложности:**
  - *Только сюжет* — прохождение без ограничения по времени.
  - *На смерть!* — режим с таймером обратного отсчёта (10 секунд на ответ) и автоматическим переходом при истечении времени.
- **Интерактивная проверка:** визуальная индикация правильного и ошибочного ответа перед переходом к следующему вопросу.
- **Экран результатов:** подсчёт набранных баллов, присвоение тематического ранга и возможность вернуться к выбору сложности для повторного прохождения.
- **Обработка ошибок:** отображение экрана-заглушки при отсутствии или некорректном формате файла с вопросами.

## Стек и структура проекта
- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Асинхронность:** Kotlin Coroutines (работа таймера и задержек интерфейса)
- **Парсинг данных:** стандартный `org.json`

Основные файлы приложения (`app/src/main/java/com/example/witcherquiz/`):
- `Question.kt` — модель данных вопроса.
- `QuizController.kt` — логика загрузки JSON, управления состоянием экранов, таймером и подсчётом очков.
- `MainActivity.kt` — интерфейс экранов на Jetpack Compose.
